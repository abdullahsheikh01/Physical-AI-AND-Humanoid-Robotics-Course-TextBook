# Assessments

This section contains all the assessments, projects, and evaluation criteria for the Physical AI and Humanoid Robotics course.

## Assessment Types

The course includes various types of assessments to evaluate your understanding and practical skills:

- **Hands-on Projects**: Implementation of robotics algorithms and systems
- **Simulation Tasks**: Working with Gazebo and Isaac Sim environments
- **ROS 2 Challenges**: Practical exercises with Robot Operating System
- **Capstone Project**: Comprehensive project integrating all learned concepts

## Project Descriptions

Each assessment builds upon the previous ones, ensuring a comprehensive understanding of Physical AI and humanoid robotics concepts.

For detailed information about each assessment, please see the individual project pages below.
